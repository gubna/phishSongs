# PhishSongs

A Python GUI app that randomly picks a song from Phish's 290-song catalog and displays it on screen.

## Requirements

- Python 3
- [Pillow](https://python-pillow.org/)

```bash
pip install -r requirements.txt
```

## Usage

```bash
python PhishSongs.py
```

A window will open showing the Phish logo and a randomly selected song title. Close and rerun to get a new song.
